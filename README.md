
# 📚 Sistema de Gestión de Biblioteca (V1)

Sistema de gestión de biblioteca desarrollado en **Python**, aplicando los principios de la **Programación Orientada a Objetos (POO)**.

Este proyecto fue desarrollado de manera individual como parte de mi formación en Ingeniería en Sistemas Inteligentes, con el objetivo de fortalecer mis conocimientos de programación, estructuración de código y desarrollo de software.

## 🚀 Funcionalidades

El sistema permite administrar una biblioteca mediante un menú interactivo en la terminal.

- Registrar nuevos libros.
- Mostrar el catálogo de libros.
- Consultar información de un libro.
- Editar los datos de un libro.
- Eliminar libros del catálogo.
- Registrar préstamos de libros.
- Gestionar devoluciones.
- Controlar el stock de los libros.

## 🛠️ Tecnologías utilizadas

- **Lenguaje:** Python
- **Paradigma:** Programación Orientada a Objetos (POO)
- **Interfaz:** Consola o terminal
- **Editor utilizado:** Visual Studio Code

## 📂 Estructura del proyecto

```text
Biblioteca-Python/
├── main.py
├── libro.py
├── biblioteca.py
└── .gitignore
```

### Descripción de los archivos

- `main.py`: contiene el menú principal y gestiona la interacción con el usuario.
- `libro.py`: define la clase `Libro` y sus propiedades.
- `biblioteca.py`: contiene la lógica de administración de los libros y las operaciones de la biblioteca.

## 💻 Instalación y ejecución

### Requisitos

- Python 3 instalado.
- Una terminal o editor de código compatible.

### Pasos

**1. Clonar el repositorio**

```bash
git clone https://github.com/Zahidjoe07/Biblioteca-Python.git
```

**2. Acceder al directorio**

```bash
cd Biblioteca-Python
```

**3. Ejecutar el programa**

```bash
python main.py
```

> En algunos sistemas operativos puede ser necesario utilizar `python3 main.py`.
